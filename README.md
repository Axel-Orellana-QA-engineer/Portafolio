# 🧪 Axel Orellana | Portafolio de QA Engineering

¡Hola! Bienvenido a mi portafolio de Aseguramiento de Calidad de Software. En este repositorio documento la ejecución de pruebas funcionales, de interfaz (UI), pruebas de API y validaciones de base de datos realizadas en proyectos reales y simulaciones del entorno de desarrollo.

---

## 🛠️ Tecnologías y Herramientas
* **Gestión de Pruebas y Defectos:** Jira, TestRail, Hojas de comprobación / Checklists.
* **Pruebas de API / Backend:** Postman (Validación de HTTP Status Codes, JSON/DTOs, Colecciones).
* **Bases de Datos:** SQL (PostgreSQL / MySQL para verificación de datos).
* **Entornos & Herramientas Web/Móvil:** Chrome DevTools, Android Studio (Emuladores).

---

## 🚀 Proyectos Destacados

### 1. Urban Scooter — API REST & Aplicación Móvil
* **Descripción del Producto:** Plataforma de gestión de logística, pedidos y servicio de repartidores (couriers).
* **Objetivo de Testing:** Garantizar la integridad de la lógica de negocio en el backend mediante pruebas de integración en la API y validación de la interfaz móvil.
* **Herramientas Utilizadas:** Postman, SQL, Jira, Android Studio.
* **Puntos Clave del Trabajo Realizado:**
  * Diseño e integración de colecciones de prueba en Postman para endpoints (`GET`, `POST`, `PUT`, `DELETE`).
  * Validación de códigos de respuesta HTTP (`200`, `201`, `400`, `404`, `409`) y manejo de errores.
  * Análisis de valores límite (BVA) y clases de equivalencia para la creación/eliminación de repartidores.
  * Verificación directa en base de datos mediante consultas SQL para comprobar la persistencia y eliminación de datos.

### 2. Urban Routes — Aplicación Web
* **Descripción del Producto:** Servicio web interactivo para la reserva y personalización de rutas de transporte.
* **Objetivo de Testing:** Auditar el diseño de la interfaz de usuario (UI), usabilidad (UX) y flujos end-to-end de reserva.
* **Herramientas Utilizadas:** Chrome DevTools, Jira, Hojas de comprobación.
* **Puntos Clave del Trabajo Realizado:**
  * Pruebas exploratorias por sesiones (Funcionalidad, Usabilidad y Límites).
  * Inspección de elementos de UI y consola de errores mediante Chrome DevTools.
  * Reporte y seguimiento del ciclo de vida de defectos en Jira con pasos detallados para su reproducción.
